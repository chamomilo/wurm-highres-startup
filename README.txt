HIGHRES STARTUP 0.3.9
4K Sklotopolis startup screen for Wurm Unlimited
Chamomilo shared updater 1.4.1

Replaces the stock connecting-screen image with a 3840 x 2160 illustration.
Keeps the game's native startup layout and progress display.

INSTALLATION
Requires Ago's Wurm Unlimited Client Mod Launcher:
https://github.com/ago1024/WurmClientModLauncher

1. Close Wurm Unlimited and WurmLauncher completely.
2. Extract this ZIP into the game's WurmLauncher directory and merge mods.
3. Confirm these files exist:
   mods/highres-startup.properties
   mods/highres-startup/highres-startup-0.3.9.jar
   mods/highres-startup/highres-startup-resources-0.3.9.jar
4. When updating, remove the old highres-startup-<old-version>.jar and
   highres-startup-resources-<old-version>.jar from mods/highres-startup.
5. Start the modded client. The image appears on the connecting screen.

MOD UPDATES
The Chamomilo updater opens after the game HUD is ready and is also available
through the native Mod updates menu. DOWNLOAD opens the mod's release page.
Install updates manually and restart the client.
Startup visibility and language preferences are shared by Chamomilo mods.
Languages: English, Brazilian Portuguese, German and Russian.
Updater 1.4.1 selects the newest compatible module among active Chamomilo mods.

TROUBLESHOOTING
If the stock image still appears, check the directory layout and restart
through the mod launcher. Keep both JARs together. The descriptor's
resourcePack setting must point to the resource JAR shown above.
If the artwork cannot be read, the mod falls back to the stock image.

UNINSTALLATION
Close the client. Remove mods/highres-startup.properties and the
mods/highres-startup directory.
