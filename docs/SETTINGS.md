# Settings

Settings are available from the Settings button in the shared Mods Registry. Each parameter has hover help. Valid edits are saved automatically and applied during play where supported; startup-only changes are identified in the help. The shared language selector controls the settings window.

A saved change that requires a client restart immediately shows a warning. Continue configuring keeps the game running; Exit game first saves valid pending edits and opens Wurm's normal quit confirmation. An exit offer remains in the Settings footer while restart changes are pending.

HighRes Startup's **Startup screen** selector offers `random`, `sklotopolis` and `wurm-reimagined`. Random is the default: each client launch chooses one of the two screens with equal probability. Reconnecting keeps the same image. Consecutive launches can choose the same screen.

The **Startup image resource pack** setting points to the versioned resource JAR containing the full library. Both settings require a client restart because the loading screen is constructed before the game HUD.

Open **Mod updates → HighRes Startup → Settings** to change the selection. The illustrated [screen library](../README.md#screen-library) shows both included screens.
